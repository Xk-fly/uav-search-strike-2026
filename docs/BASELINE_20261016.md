## 强制事实区分
- `GoTo`：直接目标位置控制，不经过 Ego 避障。
- `PlanningControl`：发布 `/move_base_simple/goal` 并消费 `/planning/pos_cmd`，才经过 Ego。
- `TargetLocator`：根据前视 YOLO 框尺寸/已知框尺寸估计距离，再位姿转换；并非直接融合深度点云。
- 下视 RGB `/rflysim/sensor2/img_rgb` 当前用于 ArUco；前视 RGB `/rflysim/sensor1/img_rgb` 用于 YOLO 方框与气球。
- 当前 ArUco ID 不会动态决定 `hit_balloon` 颜色，红球由自然语言任务预先指定。
